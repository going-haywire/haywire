# The development workflow

The workflow is one page in core's docs. Read it before the first branch, commit, push or
`gh pr` command of the task; the guardrail hooks refuse a commit until this session has read it:

- through the Farmhand bridge: the resource `farmhand://dev/collaboration/workflow.md`;
- as a file: `docs/collaboration/workflow.md` in core, `../haywire-repo/docs/collaboration/workflow.md`
  from an org library.
