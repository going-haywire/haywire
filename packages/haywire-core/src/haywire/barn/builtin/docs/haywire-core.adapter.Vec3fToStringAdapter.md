# Vec3fToStringAdapter

`haywire-core:adapter:Vec3fToStringAdapter` · kind: adapter

Convert a 3D float vector to text, (x, y, z)

## Details

- **converts_from**: `haywire-core:type:VEC3F`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 3D float vector to text in parentheses, `(0.5, -0.25, 1.0)`.
