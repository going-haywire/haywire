# Vec4iToStringAdapter

`haywire-core:adapter:Vec4iToStringAdapter` · kind: adapter

Convert a 4D integer vector to text, (w, x, y, z)

## Details

- **converts_from**: `haywire-core:type:VEC4I`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 4D integer vector to text in parentheses, W first, `(1, 0, -1, 2)`.
