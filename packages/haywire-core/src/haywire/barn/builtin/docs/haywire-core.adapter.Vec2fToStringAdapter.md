# Vec2fToStringAdapter

`haywire-core:adapter:Vec2fToStringAdapter` · kind: adapter

Convert a 2D float vector to text, (x, y)

## Details

- **converts_from**: `haywire-core:type:VEC2F`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 2D float vector to text in parentheses, `(0.5, -0.25)`.
