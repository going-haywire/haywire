# Mat4ToStringAdapter

`haywire-core:adapter:Mat4ToStringAdapter` · kind: adapter

Convert a 4x4 matrix to text, one bracket per row

## Details

- **converts_from**: `haywire-core:type:MAT4`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 4x4 matrix to text on one line, rows first, `[[1.0, 0.0, 0.0, 0.0], ...]`.
