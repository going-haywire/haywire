# Vec4fToStringAdapter

`haywire-core:adapter:Vec4fToStringAdapter` · kind: adapter

Convert a 4D float vector to text, (w, x, y, z)

## Details

- **converts_from**: `haywire-core:type:VEC4F`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 4D float vector to text in parentheses, W first, `(1.0, 0.0, 0.5, -0.25)`.
