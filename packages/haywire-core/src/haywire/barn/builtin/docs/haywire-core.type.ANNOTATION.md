# Annotation

`haywire-core:type:ANNOTATION` · kind: type

A link between annotation nodes; carries no value

## Details

- **wire_type**: `haywire-core:wire:AnnotationWire`
- **default**: `{'value': ''}`
- **color**: `#8e8e8e`

## Notes

A link between two annotation nodes.

It is drawn and saved with the graph but never run, so it carries no value.
Its colour, dash, width and arrow heads are set per link.
