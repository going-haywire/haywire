# Vec2iToStringAdapter

`haywire-core:adapter:Vec2iToStringAdapter` · kind: adapter

Convert a 2D integer vector to text, (x, y)

## Details

- **converts_from**: `haywire-core:type:VEC2I`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 2D integer vector to text in parentheses, `(1, -1)`.
