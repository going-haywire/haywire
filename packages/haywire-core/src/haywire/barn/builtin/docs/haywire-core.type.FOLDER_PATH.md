# Folder path

`haywire-core:type:FOLDER_PATH` · kind: type

A folder inside a named volume such as the project folder or `models`.

## Details

- **wire_type**: `haywire-core:wire:DataWire`
- **default**: `{'value': {'volume': 'haywire-core:volume:project', 'relative': ''}}`
- **widget_key**: `haywire-core:widget:PathWidget`
- **color**: `#c9a66b`

## Notes

A folder inside a named volume. Browsing offers folders only.
