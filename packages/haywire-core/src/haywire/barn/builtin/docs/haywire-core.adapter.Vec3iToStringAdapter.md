# Vec3iToStringAdapter

`haywire-core:adapter:Vec3iToStringAdapter` · kind: adapter

Convert a 3D integer vector to text, (x, y, z)

## Details

- **converts_from**: `haywire-core:type:VEC3I`
- **converts_to**: `haywire-core:type:STRING`
- **priority**: `0`

## Notes

Convert a 3D integer vector to text in parentheses, `(1, -1, 0)`.
