# Contributing

Thank you for contributing to Haywire. The rules for everyone — roles, the introduction before a
first pull request, issues, tools, making the change, the pull request, review, working with AI
agents — are one page of the docs:
[docs/collaboration/contributing.md](docs/collaboration/contributing.md)
([on the docs site](https://going-haywire.github.io/haywire/docs/collaboration/contributing/)).

Working with an AI agent? Tell it: *Set me up for Haywire: read
<https://raw.githubusercontent.com/going-haywire/haywire/master/docs/agents/start.md> and follow
it.*
