# Image

`haybale-image:type:IMAGE` · kind: type

A picture of any channel layout. Pixels are kept as made and converted on demand.

## Details

- **wire_type**: `haywire-core:wire:DataWire`
- **default**: `{'value': {'width': 0, 'height': 0, 'layout': 'gray'}}`
- **color**: `#3f8fd2`

## Notes

A picture of any channel layout; the value is never saved with the graph.
