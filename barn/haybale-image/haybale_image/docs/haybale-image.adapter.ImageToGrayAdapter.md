# ImageToGrayAdapter

`haybale-image:adapter:ImageToGrayAdapter` · kind: adapter

Convert an image to gray

## Details

- **converts_from**: `haybale-image:type:IMAGE`
- **converts_to**: `haybale-image:type:IMAGE_GRAY`
- **priority**: `0`

## Notes

Convert an image to one gray channel (luma of the colour channels).
