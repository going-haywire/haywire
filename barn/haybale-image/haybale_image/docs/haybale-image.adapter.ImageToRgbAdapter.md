# ImageToRgbAdapter

`haybale-image:adapter:ImageToRgbAdapter` · kind: adapter

Convert an image to RGB

## Details

- **converts_from**: `haybale-image:type:IMAGE`
- **converts_to**: `haybale-image:type:IMAGE_RGB`
- **priority**: `0`

## Notes

Convert an image to three colour channels, dropping transparency or repeating gray.
