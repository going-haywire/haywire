# ImageToRgbaAdapter

`haybale-image:adapter:ImageToRgbaAdapter` · kind: adapter

Convert an image to RGBA

## Details

- **converts_from**: `haybale-image:type:IMAGE`
- **converts_to**: `haybale-image:type:IMAGE_RGBA`
- **priority**: `0`

## Notes

Convert an image to colour plus transparency, fully opaque when it had none.
