# Example

Example library for Haywire node system demonstrating custom types, nodes, widgets, and renderers

## Nodes
### Examples
- **Custom Callback** — Listens for custom callbacks from other flows
- **Emit Callback** — Emits a callback to trigger event nodes in other flows
- **Math Operation** — 
- **Merge Callback** — Listens for a specified number of callbacks from other flows

## Types
- **Array** — Map with key type string
- **Simple Operations** — Simple mathematical operations for one or two float values
- **Temperature** — Temperature data types

## Widgets
- **KnobWidget** — knob widget
- **TemperatureWidget** — Temperature with unit conversion
- **ValidatedNumberWidget** — Number widget with range clamping

## Adapters
- **MapsString to Array** — Transform MapsString elements (MapsStringType[str, X] → ArrayType[Y])
