# Code Editor

`haybale-studio:editor:CodeEditor` · kind: editor

Text/code editor with syntax highlighting (Markdown, Python, JSON, TOML, YAML, JS/TS, CSS/HTML/XML, Shell, plain text). Markdown files have a Preview tab. Save and Save As supported.

## Details

- **default_slot**: `edit`
- **opens**: `OpenBehavior.ON_PAYLOAD`
- **order**: `20`

## Notes

Tiny text/code editor with optional Markdown preview.
