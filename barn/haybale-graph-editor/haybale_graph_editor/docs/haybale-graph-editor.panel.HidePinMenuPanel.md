# Hide pin

`haybale-graph-editor:panel:HidePinMenuPanel` · kind: panel

Hides this pin's row on the node card; the Ports panel shows it again.

## Details

- **surface**: `pin`
- **order**: `110`

## Notes

Hides this pin's row on the node card; the Ports panel shows it again.

Not offered on a promoted pin, which is hidden by demoting its setting.
