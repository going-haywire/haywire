# Settings reset by a code change

`haybale-graph-editor:panel:PreviousSetupSelectionMenuPanel` · kind: panel

Restore or discard the settings the active node had before a code change rebuilt it.

## Details

- **surface**: `selection`
- **order**: `1`

## Notes

Restore or discard the active node's previous setup, whatever skin draws it. See ADR 0062.
