# Arrange Flow

`haybale-graph-editor:panel:ArrangeFlowMenuPanel` · kind: panel

Lay out every node connected to the selected nodes.

## Details

- **surface**: `selection-layout`
- **order**: `10`

## Notes

Lay out every node connected to this node, keeping this node in place.

With several nodes selected, lays out every flow they touch, centred where it was.
